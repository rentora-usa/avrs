Join in three steps

  1. Open Minecraft

    Launch Minecraft: Java Edition and choose Multiplayer from the main menu.

  2. Add the server

    Select Add Server, then paste avrs.aternos.me into the Server Address box and save.

  3. Read the rules, then play

    Select AVRS and join. The rules are short and apply to everyone.
