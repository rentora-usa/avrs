FAQ

Quick answers about joining, connecting, and getting help.

What version should I play on?

Check the Version line in the status panel on the home page while the server is online.

Can I join from Bedrock, console, or a phone?

No. AVRS is Java Edition only, so you need Minecraft: Java Edition on Windows, macOS, or Linux.

The server says it's offline. What now?

The server may be stopped or restarting. Check the status panel on the home page, wait a minute and try again, and if it stays offline let a staff member know.

I get "Can't connect to server".

Run through this list:

  • The address is exactly avrs.play.hosting, with no http:// in front.
  • The server is online in the status panel.
  • You're on Java Edition and using the right version.
  • Wait a minute and try again if the server was just starting.
How do I report a player?

Tell a staff member and include the player's username, roughly when it happened, and a screenshot if you have one. Please don't confront the player yourself.

I was banned or muted. Can I appeal?

Yes. Fill out the form on the appeals page.
